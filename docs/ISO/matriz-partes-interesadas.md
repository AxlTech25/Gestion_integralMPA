# Matriz de partes interesadas

**Norma:** ISO 9001:2015, cláusulas 4.1 y 4.2  
**Versión:** 1.0  
**Fecha:** 2026-06-11

---

## Partes interesadas y requisitos

| ID | Parte interesada | Necesidades y expectativas | Requisitos / compromiso | Cómo se atiende (SGC / SGMI) |
|----|------------------|----------------------------|-------------------------|------------------------------|
| PI-01 | Ciudadanía | Trámites claros, tiempos razonables | Leyes de procedimiento administrativo | Tramitación interna eficiente (S.01); futuro M.02 |
| PI-02 | Concejo Municipal | Información para fiscalización | Normas de transparencia | Dashboard estratégico; expedientes trazables |
| PI-03 | Alcaldía / Gerencia Municipal | Visión consolidada, decisiones con datos | Política de calidad, objetivos | MOD-DASH; rol VISTA_EJECUTIVA |
| PI-04 | Gerencias de línea | Control de su área, cuellos de botella | Organigrama, delegación | Dashboard acotado a gerencia; bandeja por unidad |
| PI-05 | Servidor público operativo | Herramientas simples, soporte TI | Capacitación, accesos | SGMI por rol; incidencias formalizadas |
| PI-06 | Secretaría General | Trámite documentario ordenado | Normas documentales | MOD-DOC; tipos documentales |
| PI-07 | OCI | Auditoría, control interno | Ley de control | Auditoría SGMI; rol AUDITOR_OCI |
| PI-08 | UTIS | Inventario TI, disponibilidad | SLAs internos (sin SLA institucional formal) | MOD-PAT-TI; semáforo ML |
| PI-09 | Patrimonio (ORG-059) | Inventario oficial, custodio | SIGA, normas patrimoniales | Registro equipos; integración SIGA (planificado) |
| PI-10 | Presupuesto / Finanzas | Datos de ejecución confiables | SIAF, normas MEF | INT-SIAF lectura; dashboard restringido |
| PI-11 | MEF / SUNAT (vía SIAF) | Reportes fieles | Normas contables | Solo lectura; no modifica SIAF |
| PI-12 | Proveedores TI | Órdenes claras | Contratos | Fuera alcance SGC Fase 1 (Abastecimiento S.03) |

## Monitoreo de partes interesadas

| Actividad | Frecuencia | Responsable |
|-----------|------------|-------------|
| Revisión matriz partes interesadas | Anual | Gerencia Municipal + OCI |
| Encuesta satisfacción interna (servidores) | Anual | OCI / UTIS |
| Análisis quejas y NC | Trimestral | OCI |
| Revisión por la dirección | Semestral / anual | Gerencia Municipal |
